## 編集箇所

- `index.html`：文章・価格・内容量・電話・住所・営業案内・リンクの正本。工場での購入相談と通販への移動が主行動です。料理3点は粉の活用例です。
- `css/style.css`：冒頭の変数で色、書体、幅、余白、動作時間を管理。960／700／600px付近でナビと配置を変更します。
- `js/main.js`：小型ナビの開閉と初回の短い表示効果。外部ライブラリ、fetch、サーバーAPIは使いません。
- `assets/images/`：別々に生成した8画像。hero1536×1024、他1100×733のWebP。許諾済み実物画像への置換時は、同じ比率・ファイル名を推奨。altと寸法も内容に合わせて変更してください。
- `docs/制作方針.md`：対象客・個別構成・演出の判断。
- `docs/画像計画.md`：用途、保持条件、最終生成指示、採用結果。
- `docs/情報出典と確認待ち.md`：公式情報・相違・地図識別・公開前の確認。
- `docs/営業メール用説明.md`：提案の前提と差し替え条件。未送信。
