# 四山楼 LP

保存先：C:\Users\user\LP\234

index.htmlを直接開く静的LPです。ビルド・開発サーバーは不要。CSS・JS・WebP8画像を相対パスで同梱。Googleマップと外部リンクの表示にはインターネット接続が必要です。

- index.html：文章・メニュー・価格・店舗情報の正本。変更時は冒頭の要点・FAQ・店舗情報の相互整合を確認してください。
- css/style.css：冒頭の変数で配色・書体・余白を管理。body.cafe／body.ryoteiで店舗の調子を切り替えています。960／700／359px付近で配置・ナビを調整。
- js/main.js：ナビ開閉、短い初回登場、カフェの写真付きメニュー絞り込み。JS無効でも全本文・リンク・FAQは表示。
- assets/images：主役画像1536×1024、後続1100×733のWebP。実物写真へ置換する際は同じ比率と主題を基本にaltと寸法も更新。
- docs/制作方針.md：店舗ごとの構成・対象客・強み・演出。
- docs/情報出典と確認待ち.md：出典URL、確認日、掲載判断・店舗確認事項・地図識別。
- docs/画像計画.md：役割、観察した特徴、実際に使用した全生成プロンプト、採用結果と差し替え条件。
- docs/営業メール用説明.md：提案の前提。未送信。
- docs/確認結果.md：実施した検査と未検証範囲。

公開前に店舗へ営業情報・現行税込価格・利用条件を確認し、生成画像を同じ料理の許諾済み写真へ差し替えてください。ローカルHTMLの390／768／1440px、可能なら320pxで全体表示と全操作の確認が必要です。今回の検査範囲と制約は確認結果をご覧ください。
