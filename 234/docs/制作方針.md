# 制作方針

2026-10-27／四山楼／〒990-0042 山形県山形市七日町2丁目6-4 割烹四山楼

企画：ご接待、ご結納・お顔合わせ、ご法要などのお集まりを考える人へ、四季の会席と歴史ある料亭の趣を伝え、人数・用途・予算を電話で相談してもらう。

強みと根拠：主な強みは会席料理と大切な集いに対応する料亭であること。補助は伊藤博文公命名の歴史、登録有形文化財の主屋・蔵座敷、お弁当と贈答品。由緒・建物の事実は公式に基づく。 詳細は情報出典と確認待ち.md。

デザイン：生成り、墨色、深緑、金茶。明朝の文字組、直線と広い余白。濃い漆調の卓と和の器で、料亭の落ち着きを表現。会席は濃色背景に大きく配置し、持ち帰りは淡い背景へ切り替える。 PCは大判写真と文字の明確な大小、スマホは縦並びにして写真の縦横比を保持。食材や器を隠す極端な切り抜きは避ける。全8写真は異なる役割で1回ずつ配置し、店内・外観・人の偽の証拠写真は作らない。

構成：会席の冒頭→会席予算・営業時間・用途→歴史と公式の部屋写真へのリンク→お造り・焼き物・煮物の例→3価格の会席→慶事・接待・法要→弁当2種と贈答2種→予約FAQ→営業・地図→電話相談。

主行動：電話で相談。補助はGoogleマップ。未確認の予約代行を公式予約先として使わず、問い合わせフォームは作らない。電話は発信リンクの設置だけで、実際の発信・予約は行わない。

演出：480ms・12pxの短い初回登場。画像ホバーは1.015倍、ボタンは2px上移動のみ。reduced-motionでは表示効果・拡大・smooth-scrollを止める。画像は初期状態で表示、JS失敗でも本文・主要リンク・native detailsのFAQは読める。ナビは小画面で開閉しEscapeで閉じ、ボタンへフォーカスを戻す。

カシェルポポのみ写真付きメニュー2品の絞り込みを追加。通常HTMLに2品ともあり、JS有効時だけフィルターボタンを表示する。表示件数をaria-liveで通知。絞り込み対象外の補助メニュー3品は下に常時表示。

サーバー・ビルド不要の静的ファイル。相対CSS・JS・画像を同梱し、ローカルJSONのfetchをしない。Google地図・公式外部サイトのみネット接続が必要。ローカル保存の依頼につき公開は行わない。
