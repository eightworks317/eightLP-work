# 制作方針

2026-10-27／Cafeごはん カシェルポポ／〒990-0061 山形県山形市五十鈴3丁目1-14

企画：山形市内で、友人や家族とのランチ・おやつを探している人に、野菜を添えた洋食と自家製のお菓子を伝え、メニューを見て電話または地図へ進んでもらう。

強みと根拠：主な強みは洋食と自家製ケーキを一緒に楽しめること。補助は自家菜園の野菜も使う料理、お子さま向けメニュー、駐車場。自家菜園の野菜は全品・通年・全量と保証しない。 詳細は情報出典と確認待ち.md。

デザイン：明るいクリーム色、テラコッタ、深いセージ色。白い器と淡い木卓、自然光で日常のカフェごはんを表現。角を少し丸め、写真を大小・段違いに配置。 PCは大判写真と文字の明確な大小、スマホは縦並びにして写真の縦横比を保持。食材や器を隠す極端な切り抜きは避ける。全8写真は異なる役割で1回ずつ配置し、店内・外観・人の偽の証拠写真は作らない。

構成：オムレツハヤシの冒頭→昼食・お菓子・月曜休の要点→日替わりランチ→野菜のサラダ→写真付き主菜2品と主力メニュー→ケーキ2品とコーヒー→来店FAQ→住所と地図→電話・行き方。

主行動：電話で相談。補助はGoogleマップ。未確認の予約代行を公式予約先として使わず、問い合わせフォームは作らない。電話は発信リンクの設置だけで、実際の発信・予約は行わない。

演出：480ms・12pxの短い初回登場。画像ホバーは1.015倍、ボタンは2px上移動のみ。reduced-motionでは表示効果・拡大・smooth-scrollを止める。画像は初期状態で表示、JS失敗でも本文・主要リンク・native detailsのFAQは読める。ナビは小画面で開閉しEscapeで閉じ、ボタンへフォーカスを戻す。

カシェルポポのみ写真付きメニュー2品の絞り込みを追加。通常HTMLに2品ともあり、JS有効時だけフィルターボタンを表示する。表示件数をaria-liveで通知。絞り込み対象外の補助メニュー3品は下に常時表示。

サーバー・ビルド不要の静的ファイル。相対CSS・JS・画像を同梱し、ローカルJSONのfetchをしない。Google地図・公式外部サイトのみネット接続が必要。ローカル保存の依頼につき公開は行わない。
