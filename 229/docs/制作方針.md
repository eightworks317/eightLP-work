# 制作方針
作成日：2026-10-26
対象：瀧不動生蕎麦／〒999-3301 山形県山形市山寺4359

企画：山寺を訪ねる人に、更科と田舎の食べ比べ、そばと天ぷらやかいもち揚げを伝え、地図を見て昼食に立ち寄ってもらう。
主行動：Google マップ／補助：電話で営業確認。

主な魅力：白い更科と田舎そばを一度に味わう合い盛り。補助は温かい鴨汁と冷たいそばの組合せ、そばがきのかいもち揚げ。観光案内の掲載を根拠とし、創業年・製法の細部・自家製・石臼・水の産地等は創作しない。

世界観：「昼の光・そばの白・山寺の緑」。白い更科を主役にする明るいオフホワイト、明瞭な濃緑、控えめな朱赤。墨背景や高級料亭的な内装演出は使わない。大きな明朝見出しと細い罫線、料理を文字で隠さない横長写真。コピーは山寺の散策と昼食を結び付ける。

構成：
1. 店名とナビ／主CTA。
2. 「山寺を歩いて、そばにほどける。」大判合い盛り写真、料理名・掲載価格2,530円を隣接。
3. 営業時間・不定休・山寺駅・駐車場の要点（台数は情報相違のため不掲載）。
4. 更科と田舎の食べ比べ（2専用写真）＝主な強みの深掘り。
5. おしながき：天ざる1,880円、天ぷらそば1,280円、鴨汁板、つめたい肉中華。合い盛りと温天ぷらは2026年8月投稿の実メニュー写真、天ざるは2026年4月の来店投稿を採用。鴨汁板・肉中華・かいもち揚げは現行価格未取得のため金額を載せない。旧観光サイト値との差を出典資料へ記録。
6. かいもち揚げを大きく紹介（価格未取得）。
7. 山寺散策と昼食の案内。架空の店内写真なし。
8. FAQ（営業確認・駐車場・料理、電話案内）。アレルギー相談は常時表示。
9. 店舗情報とGoogle地図、外部マップ。
10. 最終CTAとフッター。

演出：初回12pxフェード、マウスのみ画像1.025倍拡大、ナビ・開閉の短い反応。reduced motionでは動きなし。初期HTMLを表示し、JSエラーでも本文・FAQ・リンクを維持。自動スライド・カウントダウン・ローディング待ちなし。

スマホ：冒頭の料理とコピーは上下。ハンバーガーは小型展開、Escape・リンク選択で閉じる。下部固定CTAは地図と電話の2つ、安全領域とフッター余白。料理は4品なので絞り込みを設けず全件一覧。FAQはHTML標準のdetails。

未確認：料理・価格の現行性、税込／税別、人数・盛り量、そばの配合、そば茶／薬味等の細部、正確な営業時間（媒体相違）、駐車条件・台数、決済・予約条件。生成写真8点を実物と断定しない。LPに制作事情を表示せず管理資料・営業メール用説明で共有。ローカル保存のみ。


営業表示はGoogle マップの当日閲覧値11:00–15:30を採用。観光団体案内の10:30開始と相違があるため、店舗情報の直下に電話での営業確認を案内。詳細は出典資料へ。
