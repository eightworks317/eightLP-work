# 制作方針

2026-10-28／食彩播

対象・主行動：山形駅周辺で夕食や会食を考える方に、季節の食材によるおまかせと地酒を伝え、料理・予算を電話で相談してもらう。

強み・根拠：山形・東北の旬の食材、献立が仕入れで変わるおまかせが中心。補助は日本酒とワイン、個室・カウンターの相談、駅からの距離。 根拠のURLと不確かな項目は情報出典と確認待ち.mdへ記録。

世界観・表現：濃い墨緑、生成り、柔らかな金茶。冒頭は大判料理写真と文字を左右に、料理紹介は濃色の背景へ。日本酒とワインまで落ち着いた夜の流れをつくる。 現地の室内・外観・人の架空写真は作らない。写真は料理や酒器に限定し、3:2で全景を維持。店ごとに構成、見出し、写真の大小・背景を変える。

構成：冒頭（料理・来店目的・行動）→営業要点→各店の特徴→料理の一例と用途別の案内→FAQ・電話→店舗情報とピン付き地図→最後の行動案内。店ごとの独立画像は8点。文章・住所・営業時間・リンクは初期HTMLを正本とする。

演出：短い登場（12px・480ms）と写真1.015倍・ボタン2pxの控えめな動き。reduced-motionで停止。JavaScript無効時も主要情報とFAQは可視。小画面ではナビが開閉しEscapeで閉じ、電話と地図の2CTAを固定し安全領域を確保。固定CTA分の下余白あり。

作成物はindex.htmlを直接開く静的構成。画像・CSS・JSは相対パスで同梱。サーバー・ビルド・ローカルJSONのfetchは不要。Google地図と外部サイトはネット接続が必要。店舗確認済み写真や価格へ差し替えたうえで正式公開する。
