# 制作方針

2026-10-26／山形蕎麦の焔藏 山寺店／山形県山形市山寺4273-1

企画：山寺を訪れる人に、山形の十割そばと郷土のひと皿・甘味を伝え、山寺駅前の店へ地図を見て立ち寄ってもらう。観光の昼食・参拝後の休憩を主な利用場面とする。

主行動はGoogle マップ。補助はおしながきと電話での営業確認。予約なし・来店順の案内を店舗監修FAQから掲載し、架空の予約フォームは作らない。

主な強み：自家製粉・手打ち・つなぎを使わない十割そば。香りとコシを楽しむ価値を大きな一枚の板で伝える。根拠は公式こだわりページ、店舗監修の観光記事、店舗掲載ぐるなび。補助の強みは、芋煮・玉こんにゃくで山形の食を知ること、そば玉ずんだで食後も楽しめること、山寺駅前で訪ねやすいこと。

世界観：「力強い蕎麦・素朴な木・旅の余白」。濃い藍墨、生成り、焔を思わせる錆朱を組み合わせる。淡い天然木の板と灰褐色の麺を黒い卓で引き立てる。写真を左、短い大きな明朝コピーを右にした冒頭。丸角カードの反復を避け、写真・原料・3品の料理・2品の郷土食・甘味・歴史・店舗情報で密度を変える。和風という理由だけで縦書き・金色を増やさない。

構成と役割：
1. 店名・主要リンク・地図。認知と移動。
2. 十割板そばの大判写真、コピー「山寺で味わう、蕎麦そのもの。」、並1,650円／数量限定。料理と予算を伝える。
3. 山寺駅前・11:00–15:00（LO14:30）・水曜定休の3要点。
4. 十割／自家製粉／手打ちと最上早生。原料の静物1点で食の背景を伝え、製造設備・農場を創作しない。
5. 十割げそ板2,035円・十割天板2,365円（両方並、数量限定）・冷たい肉そば並770円の専用3写真。原稿と価格を近接。
6. 芋煮660円・玉こんにゃく110円、専用2写真で郷土食。単位・盛りは要確認。
7. そば玉ずんだ638円、専用1写真と緑のアクセントで食後の見せ場。
8. 「おのや」の伝統を継ぐ店の背景。公式の事実を短く紹介し、現在店が1501年創業との誤読を避ける。
9. 来店順・アレルギー・駐車場所の問い合わせ案内。重要事項は常時表示、補足FAQはdetails。
10. 店舗情報＋Googleの正しい店舗ピンの埋め込み、同じ店舗への外部リンク。締めの地図CTA、公式リンクとフッター。

見せ場：冒頭は無塗装の木板に広がる蕎麦。中盤は芋煮・玉こんにゃくとそば玉ずんだを、食の旅として異なる写真サイズで紹介。

演出：初回のみ12px・約480msの淡い登場と、マウス時だけ料理写真1.025倍拡大。操作は200ms以内で反応。ナビは小型展開、Escapeとリンク選択で閉じる。モバイルは通常の縦並びと電話・地図の2固定ボタン。reduced-motionで登場・拡大・smooth-scrollを無効化。初期HTMLはすべて見え、JS失敗でも本文・リンク・FAQを読める。
