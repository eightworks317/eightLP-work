# 山形蕎麦の焔藏 山寺店 LP

保存先：`C:\Users\user\LP\230`

`index.html`を直接開いて閲覧する静的LPです。HTML、CSS、JavaScript、画像をすべて相対パスで同梱しています。ビルド・確認用サーバー・外部ライブラリ・ローカルJSONのfetchは不要です。地図・外部リンクにはインターネット接続が必要です。

## 編集する場所

- `index.html`：文章、メニュー・価格、電話、住所、営業時間、リンクの正本。営業時間は冒頭の要点・FAQ・店舗情報を合わせて更新してください。
- `css/style.css`：冒頭のCSS変数で色・書体・幅・余白・反応速度を管理。幅960／700／600px付近でナビ・主要配置を切り替えます。
- `js/main.js`：ナビ開閉と初回の短い登場効果のみ。JS無効でも本文・主要情報・リンク・FAQを読める構成。
- `assets/images/`：独立した生成画像8点。ヒーロー1536×1024、他1100×733のWebP。同じ名前の許諾済み実物写真へ置換し、必要ならalt・width/heightも変更してください。
- `docs/制作方針.md`：対象客・強み・構成・配色・演出。
- `docs/情報出典と確認待ち.md`：出典、地図の店舗識別、媒体の差異、公開前の確認事項。
- `docs/画像計画.md`：各画像の役割、最終プロンプト、修正・採用結果。
- `docs/営業メール用説明.md`：提案の前提・素材置換・調整範囲の説明。未送信。
- `docs/確認結果.md`：実施済み検査と未検証事項。
