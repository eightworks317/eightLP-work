## 編集箇所

- `index.html`：文章、料理の一例、住所、電話、営業時間、定休日、リンクの正本。単品注文の価格表を作らず、おまかせの内容・予算を電話で案内する構成です。料金確定後は料理名の近くへ追加できます。
- `css/style.css`：冒頭の変数で配色・書体・幅・余白・反応速度を管理。960／820／600px付近でナビ・レイアウトを変更。冒頭の縦書きh1は820px以下で横書きに戻ります。
- `js/main.js`：小型ナビ開閉と初回の短い表示効果。外部ライブラリ、fetch、サーバーAPIは不要。JS無効でも本文・リンク・FAQを読めます。
- `assets/images/`：別々に生成した料理・地酒画像8点。hero1536×1024、他1100×733のWebP。実物画像へ置換するときは、同じ比率を基本にaltと寸法も調整してください。
- `docs/制作方針.md`：対象客・構成・店ごとのデザイン判断。
- `docs/画像計画.md`：画像の役割・最終生成指示・修正・採用結果。
- `docs/情報出典と確認待ち.md`：出典、媒体差、地図識別、店舗への確認事項。
- `docs/営業メール用説明.md`：提案の前提と差し替え条件。未送信。
- `docs/確認結果.md`：実施した検査と未検証の範囲。
