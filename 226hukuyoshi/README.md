# 麺屋 福よし｜営業提案用LP

`index.html` をブラウザで開くと閲覧できます。ビルドやインストールは不要です。画像はローカル同梱、地図のみインターネット接続が必要です。

## ファイル
- index.html：ページ構成と店舗情報
- style.css：PC／スマートフォン対応デザイン
- content.js：メニュー情報・地図リンク・コピー用住所
- script.js：メニュー絞り込み、モバイルナビ、住所コピー
- assets/ramen-hero.webp：AI生成イメージ

## 情報と素材
公式サイト https://www.fuku-yoshi.com/ を2026年10月22日に参照。メニュー、営業時間、定休日、食材の説明は同サイトの掲載情報に基づきます。価格等は最新情報の店舗確認が必要です。SNSリンクは店舗掲載情報も参照しています。

これは店舗公式サイトではなく、営業提案用の非公式サンプルです。写真は実物ではありません。店舗の許諾後に、実際の写真、最新の料金、営業時間、店舗説明へ変更してください。架空の口コミ・実績・電話番号・予約機能は設けていません。来店導線は地図へのリンクです。

公開前の確認：店舗の公開承認、写真の利用許諾、メニュー価格と税込表記、営業情報、SNSリンク、地図ピンの位置、問い合わせ先。確認後にサンプル表示と noindex を必要に応じて変更します。
