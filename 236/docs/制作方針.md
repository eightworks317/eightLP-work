# 制作方針

2026-10-28／レストラン ラ・ベルジュ

対象・主行動：会食や大切な方との食事を考える人に、和と洋が響き合う料理を伝え、予算・日時を電話で相談してもらう。

強み・根拠：和食とフランス料理を取り合わせた食事が中心。補助は前菜から食事・デザートまでの体験と小立の立地。料理の内容・順序は季節や予約により変わる。 根拠のURLと不確かな項目は情報出典と確認待ち.mdへ記録。

世界観・表現：柔らかなアイボリー、浅いオリーブと墨茶。冒頭を横長写真と上下の余白で見せ、料理の流れを交互配置で読み進める。 現地の室内・外観・人の架空写真は作らない。写真は料理や酒器に限定し、3:2で全景を維持。店ごとに構成、見出し、写真の大小・背景を変える。

構成：冒頭（料理・来店目的・行動）→営業要点→各店の特徴→料理の一例と用途別の案内→FAQ・電話→店舗情報とピン付き地図→最後の行動案内。店ごとの独立画像は7点。文章・住所・営業時間・リンクは初期HTMLを正本とする。

演出：短い登場（12px・480ms）と写真1.015倍・ボタン2pxの控えめな動き。reduced-motionで停止。JavaScript無効時も主要情報とFAQは可視。小画面ではナビが開閉しEscapeで閉じ、電話と地図の2CTAを固定し安全領域を確保。固定CTA分の下余白あり。

作成物はindex.htmlを直接開く静的構成。画像・CSS・JSは相対パスで同梱。サーバー・ビルド・ローカルJSONのfetchは不要。Google地図と外部サイトはネット接続が必要。店舗確認済み写真や価格へ差し替えたうえで正式公開する。
